## Server Manager

After installing Windows Server 2022, I used Server Manager as the main administrative console for configuring the server.
Window Server allows access to various tools like Active Directory Users and Computers, Group Policy Managements, and etc...
I also used the Window Server to set up a domain controller as mylab.local domain.
