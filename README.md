## Introduction

This project is a hands-on home lab utilizing Windows Server Active Directory using VirtualBox as the virtual machine. The main goal of this lab for me was to learn and practice the various different IT support and system administration tasks.

Throughout the project, I configured Active Directory Domain Services, DNS, organizational units, user accounts, security groups, domain-joined computers, file sharing and permissions, Group Policy, and account lockout settings. I also practiced common help desk tasks such as resetting passwords, enabling and disabling accounts, unlocking users, and troubleshooting authentication and network connectivity issues.

This lab helped me better understand how Windows domain environments are structured and how IT administrators manage users, computers, permissions, and policies in a centralized environment.
